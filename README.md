# Домашнее задание 7. Сборка конвейера CI/CD

## Задание

Научиться применять стратегии безопасного развертывания (Blue-Green и Canary) для ML-моделей и автоматизировать процесс деплоя через CI/CD (GitHub Actions).

## Стратегия деплоя

### Выбранная стратегия: Canary Deployment (канареечный деплой)

**Почему canary:**
- Минимальный радиус взрыва — при ошибках страдают только 5-10% пользователей
- Быстрый автоматический откат (менее 5 минут)
- Реальное тестирование модели в продакшене
- Zero downtime

**Как работает:**
```
95% трафика → Стабильная модель (stable)
 5% трафика → Новая модель (canary)
         ↓
  Мониторинг метрик (15-30 минут)
         ↓
   Если метрики OK → canary становится stable
   Если ошибки → canary отключается
```

### Риски и их митигация

| Риск | Митигация |
|------|-----------|
| Дрейф данных | Автоматический откат при падении точности >5% |
| Задержки в роутере | Health-чеки каждые 30 секунд |
| Ошибки A/B-теста | Sequential testing для ранней остановки |
